# 🧠 Web Application for Dyslexic Students

An AI-powered, accessible learning platform designed to support dyslexic learners through personalized progress tracking, multimodal content, and real-time error detection using deep learning.

## 🎯 Objective

To create an inclusive educational platform that addresses the unique learning challenges of dyslexic students by integrating assistive technologies like Text-to-Speech (TTS), Speech-to-Text (STT), handwriting recognition, and adaptive content recommendations.

---

## 🚀 Features

- 🔐 **User Authentication** – Secure login/signup using PHP and MySQL
- 📊 **Progress Tracking** – Individual learning analytics shown via dynamic pie charts
- ✍️ **Handwriting Error Detection** – Integrated CNN-based model with real-time feedback via Flask API
- 🔊 **Text-to-Speech & Speech-to-Text** – Voice support powered by Google Cloud and Azure APIs
- 🎓 **Multimedia Lessons** – Curated video/audio lessons and interactive learning tools
- 🎯 **Adaptive Learning** – TF-IDF-based recommender system for content based on user needs
- 🌈 **Dyslexia-Friendly UI** – Designed with accessible fonts, color schemes, and layout

---

---

## 📈 Model Performance

- **Accuracy**: 88.89%
- **Recall (Dyslexia detection)**: 1.0 (Perfect)
- **F1 Score**: 0.9412
- **Model Type**: CNN + Dense Layers + Annotation-based Features
